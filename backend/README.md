# Ilqaa - Audio Transcription Analyzer

A simple Python tool that transcribes audio files and analyzes speech patterns.

## Features

- Transcribe audio files (MP3, WAV) to text
- Analyze speaking pace (words per minute)
- Detect pauses and filler words
- Generate text and HTML reports
- Supports English and Arabic

## Quick Start

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the analyzer:

```bash
python audio_analyzer.py
```

3. Enter your audio file path when prompted

## Requirements
* Python 3.7+
* FFmpeg (brew install ffmpeg on macOS)

## Output
Generates two report files:
* Text report with analysis results
* HTML report with visual metrics
